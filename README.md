# DayNest · 日有安排

原生 macOS 待办与科研日程应用。SwiftUI + AppKit，无第三方依赖，macOS 14 或更新版本。

## 下载与安装

在 GitHub 仓库的 **Releases** 页面下载 `DayNest-1.0.0-macOS-arm64.zip`，解压后将 `DayNest.app` 拖入「应用程序」。适用于 Apple Silicon（M1/M2/M3/M4 等）与 macOS 14+；Intel Mac 请从源码构建。

发行包采用 ad-hoc 签名，尚未通过 Apple 公证。首次启动若被 macOS 拦截，请确认下载来源和 SHA256 校验值，再通过「系统设置 → 隐私与安全性 → 仍要打开」启动。无需关闭系统安全保护。

```sh
shasum -a 256 DayNest-1.0.0-macOS-arm64.zip
```

与 Release 附带的 `SHA256SUMS.txt` 比较校验值。

## 使用

双击 `dist/DayNest.app`。可将它拖入「应用程序」文件夹。

- **我的一天**：今日待办、逾期事项、今日会议、未来六个月的 CCF-A AI 截稿和置顶备忘。
- **待办计划**：新建、编辑、完成、删除；按截止日期查看今日、本周、本月，支持优先级、备注、搜索。周一是一周的开始；这些视图是日期范围，会相互包含。
- **学术 DDL**：直接同步 [ccfddl.com 官方 RSS](https://ccfddl.com/conference/deadlines_en.xml)，展示来源中所有已公布、尚未截止的 CCF-A 会议，以及 EMNLP；不限领域和未来时长。摘要和全文截止单独列出，保留多轮投稿。可按关键词和关注筛选。尚未公布具体截止时间的会议不会推测补全。
- **会议日程**：按天浏览，设置主题、开始／结束时间、参与人、地点或会议链接、议程和会议记录；支持跨日会议及时间冲突提示。这里仅保存安排，不向参与人发送邀请。
- **备忘录**：编辑、搜索、置顶和删除。最近修改的一篇置顶备忘显示在桌面。
- **桌面小窗**：点击左下角「打开桌面小窗」，拖动顶部移动位置，拖动边缘改变大小。可直接添加和完成待办；完成后以勾选、删除线和「已完成」标记保留，并播放轻量星点动画（遵循系统减少动态效果设置）。今天完成的逾期任务也会保留在今日日程中，支持再次点击勾选图标撤销完成。所有事项（包括已完成事项）的标题和右侧备注均可点击，打开编辑窗口修改标题、备注、日期和优先级，或确认删除。备注以较小、较浅的字体显示在标题右侧；较长内容可在编辑窗口查看全文。切换今日／周／月，查看会议、CCF 截止日期和置顶备忘，内容较多时可滚动查看。点击 CCF 区域「选择常驻会议」，或在学术 DDL 列表勾选「常驻桌面」，可从全部未来 CCF-A 会议与 EMNLP 中选择固定展示的会议，选择面板支持搜索。自选列表同时用于首页与桌面小窗；截止后仍保留，取消最后一项后显示空列表，不会自动补入其他会议。关闭「自定义常驻会议」可恢复未来六个月 AI 会议的自动展示。选择随本地数据保存并纳入备份；同步时更新所选会议的截止时间，源中暂时缺失时保留缓存。
- **置顶切换**：小窗右上角图钉切换「贴在桌面」与「始终置顶」。窗口位置、大小、可见状态会被记住。菜单栏叶子图标可再次打开主窗口和小窗。关闭主窗口不会退出程序，`⌘Q` 才会退出。
- **备份**：左下角「本地存储与备份」可导出 JSON、合并导入，以及打开数据目录。合并以本机同 ID 记录为准。

## 桌面形式说明

当前版本是 AppKit 常驻桌面小窗，**不是系统 WidgetKit 小组件**，不会出现在系统「编辑小组件」列表。应用运行时小窗才会显示；退出应用后会消失。系统「显示桌面」、台前调度和全屏空间对窗口的处理可能与系统小组件不同。可手动将应用加入「系统设置 → 通用 → 登录项」，随登录启动。

本项目采用无需完整 Xcode 即可构建的 AppKit 桌面小窗方案。

## 数据与时间

所有个人记录和会议缓存保存在：

```
~/Library/Application Support/DayNest/data.json
```

写入采用原子替换。发现损坏数据时暂停写入并展示原路径，避免覆盖原文件；应先导出当前内容并备份原文件，再修复 JSON 或移走损坏文件后重启并合并导入。未配置云同步、系统通知或日历账户同步。

启动时和运行中每 6 小时同步会议，可手动刷新。失败时保留缓存并显示错误。首次同步失败可手动重试，运行中也会定期再次同步。网络仅用于读取官方 RSS。截止时间依据 RSS `pubDate` 的 UTC 偏移解析，包含 UTC-12 / AoE，界面显示当前系统时区和源时间。数据完整性与更新速度取决于 ccfddl.com；投稿前请核对会议官网。

## 从源码构建

要求 Apple Command Line Tools（Swift 5.9+），不要求完整 Xcode。输出使用本机架构；本次交付是 Apple Silicon arm64，Intel Mac 可从源码重新构建。

```bash
cd DayNest
swift scripts/make-icon.swift dist/AppIcon.iconset
iconutil -c icns dist/AppIcon.iconset -o dist/AppIcon.icns
./scripts/build-app.sh
open dist/DayNest.app
```

使用本地 ad-hoc 签名，不是 Apple 公证发行版。

## 验证

```bash
./scripts/test.sh
curl -fsSL https://ccfddl.com/conference/deadlines_en.xml -o /tmp/ccfddl-feed.xml
CCF_FEED_FIXTURE=/tmp/ccfddl-feed.xml ./scripts/test.sh
```

测试覆盖 CCF-A 过滤、AoE 转换、无效源保护、周／月边界、持久化、跨日会议、损坏数据保护和链接校验；可选使用真实 RSS。测试以独立 Swift 可执行文件运行，不依赖完整 Xcode 才有的 XCTest。

## 待办文件夹与会议专属待办

- 桌面日程按「未分类」及普通文件夹分组，点击组标题折叠／展开，状态自动保存。组标题右侧「＋」直接在组内创建任务，打开图标可查看不限日期的全部任务。
- 点击桌面「管理文件夹」或主界面「待办计划 → 管理待办文件夹」新建、重命名普通文件夹。删除普通文件夹时任务移到未分类，不丢失内容。
- 编辑任意任务时可选择文件夹，支持移动已有任务。
- 点击桌面常驻会议自动创建并打开会议专属文件夹。同一会议同一年份的摘要、全文和多轮投稿共用一个文件夹，重复打开不会重复创建。取消会议常驻不会删除其任务，仍可从管理文件夹进入。
- 会议文件夹支持新增、完成、修改、备注、删除待办，保留完成动画；专属任务不出现在普通日程、逾期和完成计数中。会议窗口显示所有日期的任务。
- 文件夹、任务归属及折叠状态随 JSON 一起保存和备份；旧版记录自动归入未分类。

## 打包发行版

```sh
./scripts/package-release.sh
```

ZIP 与 SHA256 校验文件位于 `dist/release/`。打包只包含应用，不包含用户数据。
