# Changelog

## 1.0.0 — 2026-09-21

First public release of DayNest, a native macOS planner for daily work and research.

- Today, week and month tasks with priorities, notes and completion effects.
- Collapsible task folders and persistent desktop panel.
- All upcoming CCF-A conference deadlines plus EMNLP from ccfddl.com.
- Custom pinned conferences with dedicated task folders.
- Daily meeting schedules, conflict hints and pinned memos.
- Local JSON storage, backup export/import and corrupted-file protection.
- Requires macOS 14 or later. Initial binary supports Apple Silicon (arm64).
